Works fully offline

Your logs, goals and saved dishes live in one local SQLite file (macromax.db). Logging, search and charts all work without a connection, and your history survives app updates.

8,379 foods ready to log

Indian (IFCT 2017) and USDA foods are bundled and searched on-device in under 3 ms. Anything missing is looked up online and cached for next time.

Lock and save the day

Once a day is reviewed, lock it. Entries can't be changed by accident, so your 7-day averages stay accurate.

Export and restore with JSON

Export your full history as readable JSON through the Android share sheet. Restore it on a new device and MacroMax checks the file before importing.

Build it yourself

MacroMax is MIT licensed. Clone the repository and build a release APK with Expo and Gradle.

bash
# Clone the repository
git clone https://github.com/sebastian2006-dev/MacroMax.git
cd MacroMax

# Install dependencies and set up env
npm install
cp .env.example .env

# Build the release APK
npx expo prebuild
cd android && ./gradlew assembleRelease
